# rmyc-robot-framework

A coding support framework for RoboMaster Young Champion Series Robot EP/S1

这是一个用于辅助 **RoboMaster** 软件中 Python 编程的框架，旨在利用 VSCode 的强大功能取代鸡肋的原生 IDE，提升编程体验。

## 使用方法

### 1. 下载或克隆本仓库到本地并使用 VSCode 打开该文件夹。

```shell
$ git clone https://github.com/n1ghts4kura/rmyc-robot-framework.git
```

### 2. 在 `src/` 目录中编辑你的代码。

注意：一定要在 `src/` 目录中编辑代码，并在代码主体前添加 `from linting import *` 以提升代码编辑体验。  

> 你要是不这么干的话不如回去用原生 IDE 吧。  
> 那我这个项目存在的意义是什么。  
> **T_T**  

### 3. 访问官方文档了解 API 详情。
[\[RoboMaster Young Champion Series 开发者文档\]](https://robomaster-dev.readthedocs.io/zh-cn/latest/python/apis.html)

### 4. 使用 `complie.py` *检查* 代码是否合规。

```shell
$ python complie.py
```

### 5. **删除** `from linting import *` 语句并将代码复制到 RoboMaster 软件中运行。
